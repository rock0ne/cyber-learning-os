# Method traceability

Cyber Learning OS is inspired by Dr Justin Sung's video
[My Exact 14-Step Guide To Learn Anything Faster](https://youtu.be/CQQTwvDb5xg).
This record identifies the source segment used for each principle. The app paraphrases
the ideas and adds original interaction design, diagrams, cybersecurity exercises and
evidence gates. It does not reproduce the source flowchart or claim endorsement.

| Step | App lesson | Source segment | Teaching technique added in the app |
|---:|---|---|---|
| 1 | Measure outcomes, not speed | 1:04–2:24 | Outcome scoreboard: depth, delayed retention and transfer |
| 2 | Set a clear purpose and plan | 2:27–3:37 | Purpose/objective/performance/evidence canvas |
| 3 | Build an actual schedule | 3:38–4:17 | Task-to-time-block matching |
| 4 | Plan for priming | 4:18–5:27 | Bounded preview before intensive study |
| 5 | Prime for the gist | 5:28–6:55 | Five-to-ten-minute gist map |
| 6 | Create a focused environment | 7:14–7:51 | Distraction sheet and trigger redesign |
| 7 | Make connections the priority | 7:53–10:52 | Schema-building comparison questions |
| 8 | Take relational notes | 10:54–12:24 | Central question, labelled links, cross-links and evidence |
| 9 | Individualise the learning order | 12:25–13:45 | Hard point → missing context → easier node → return |
| 10 | Use confusion as a compass | 15:25–19:15 | Conflict-to-question-to-hypothesis loop |
| 11 | Match the challenge | 19:16–21:01 | Style/level/cue challenge matcher |
| 12 | Attempt before feedback | 21:02–23:22 | Closed-book generate/freeze/feedback/correct boundary |
| 13 | Test at the right frequency | 23:23–24:58 | Forgetting-based interval calibration |
| 14 | Match the conditions that matter | 24:59–26:37 | Time/scrutiny/uncertainty pressure rehearsal |

The transcript supplied during development is a research input, not a redistributable
application asset. This traceability record is the durable, proportionate citation.
